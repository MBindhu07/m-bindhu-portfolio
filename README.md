# M Bindhu — Professional Resume Portfolio

This portfolio is built directly around the information in the supplied resume.

## Included
- Semantic HTML5
- CSS Grid for major layouts
- Flexbox for component alignment
- Mobile-first responsive architecture
- Light/dark mode using CSS custom properties
- Responsive navigation
- Scroll progress indicator
- Reveal animations
- Professional project, skills, experience, education and certification sections
- Email, LinkedIn and GitHub contact links
- No phone number displayed anywhere
- No framework or build process required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Resume accuracy
The content follows the supplied resume. The phone number has intentionally been excluded from the website.

## Personalization
The resume already supplied the email, LinkedIn and GitHub links, so those are included. Update them only if your details change.
